LyonPotpourri Change log

Version 3.0.2

Modernize click2float~ for Max 8/9 and fix thread safety

- Replace scheduler clock with t_qelem for thread-safe UI outlet emission
- Add click2float_free destructor to properly clean up qelem and unhook DSP
- Prevent perform64 execution when signal inlet is disconnected (count[0])
- Update macOS deployment target to 12.0 for modern Xcode compatibility

Modernize buffet~ for Max 8/9: fix buffer lock leaks, DSP perform routing, and bounds safety

- Eliminate buffer lock leaks: ensure buffer_unlocksamples() is guaranteed across all early returns and error conditions.
- Fix 64-bit perform routine: configure dsp_setup with 1 signal inlet for groove sync and eliminate invalid dereference of nonexistent signal outlets in perform64.
- Prevent undefined behavior in buffet_rotatetozero: replace sysmem_copyptr with standard memmove for overlapping sample buffers.
- Fix null dereference in buffet_copy_to_mono_buffer: correct destination sample lock validation.
- Harden message handling: add strict argc bounds checks across all A_GIMME methods to prevent out-of-bounds atom reads on malformed messages.
- Fix trimzero completion logic: ensure completion bang fires on no-op/silent buffers and correctly handle leading/trailing silence trimming.
- Modernize method signatures to use long argc in conformance with Max 8/9 SDK standards.

Modernize granule~ for Max 8/9: fix memory leaks, buffer lifecycle crashes, and mute handling

- Register granule_dsp_free in class_new to eliminate severe memory leaks of grain structures, pitch grids, and buffer reference handles upon deletion.
- Fix null dereference and infinite loop in granule_perform64 when encountering empty (zero-frame) or invalid buffers.
- Fix copy-paste bug in granule_setbuf: properly bind and validate the window buffer independently rather than checking the wavetable twice.
- Implement granule_notify callback to ensure dynamic buffer reloads, resizing, and replacements are tracked cleanly.
- Register and implement the "mute" message in main() and perform64 to bypass DSP calculation when inactive.
- Harden message handling: add bounds checks across grain, grist, and setscale routines to prevent out-of-bounds atom reads.
- Modernize memory management from legacy t_getbytes/t_freebytes to sysmem_newptrclear and sysmem_freeptr.
